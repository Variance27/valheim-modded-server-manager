            Scheduled backups
            
              
            Loading…
            
            
            
          
            
          
            
            
            
            
            
          
            
          
            
          
            Saving installs a real cron job on the VPS (/etc/cron.d/valheim-gui-backup), so backups run on their own even when this dashboard and your PC are off. Each run stops the server cleanly (which saves the world), archives it, uploads and prunes old copies, then starts the server again — about a minute of downtime. It is skipped while the server is stopped. With “only when nobody is online” a run that finds players connected is postponed and retried every 15 minutes (up to 12 hours) until the server is empty. If a backup fails after stopping the server, the server is started again automatically. “Run backup now” shares a lock with the scheduled job, so the two can never overlap. Turn the schedule off here to delete the cron job.

              Worlds
              
            
              Run several worlds at the same time. Each world is its own server (own game account, port, mods, backups). Pick one to manage it from the other tabs.
              
          
              
          
              
            
            
          
              
        
              
        
              
        
              
          
          
              Every world needs its own game port (a Valheim server uses its port and the next two, so worlds are 10 apart: 2456, 2466, 2476, ...). Open the UDP range for each world in your VPS or cloud firewall. Each extra world installs its own copy of the server (about 2 GB of disk) and its own mods.
              
        
              
      
              

      
      
              
        
              
          
              
            
              First-time setup
              
            
              Take a fresh Ubuntu/Debian VPS to a working modded server, top to bottom. Each step checks what's done and skips ahead, so you can re-run any of them.
              
            
              
          
              
          
              
            
          
              
        
              

        
              
          
              
            
              Environment checks—
              
            
              
          
              
          
              
          
              
        
              

        
              
          
          
              Before you start. The GUI must be able to run commands as root on the VPS (SSH as root, or the GUI running on the VPS as root). Work through the steps in order and keep this page open while a step is running. Step 5 edits LinuxGSM's common.cfg (backed up first). Nothing starts the game until you press Start in step 8.
              
        
              

        
                
          
              1. 
            
                1
                
            
                
              
                
                
                Install LinuxGSM
                
                
              
                
              
                Creates the game account (lgsmUser, default vhserver), installs the packages LinuxGSM needs (32-bit libraries, tmux, cron, curl, unzip, python3, sudo) and downloads LinuxGSM for Valheim. Ubuntu and Debian only. Safe to run again.
                
              
                
                
                Output
                
                
                
              
                
            
                
          
                2. 
          
              2. 
            
                2
                
            
                
              
                
                
                Install the Valheim server
                
                
              
                
              
                LinuxGSM downloads the Valheim dedicated server from Steam (about 1–2 GB, several minutes — keep this page open) and creates its config files. Re-running just validates the files.
                
              
                
                
                Output
                
                
                
              
                
            
                
          
                3. 
          
              3. 
            
                3
                
            
                
              
                
                
                Name the server and world, set a password
                
                
              
                
              
                These are LinuxGSM settings. Valheim refuses to start without a password. The world is created the first time the server starts, and the GUI then shows that world name everywhere. Changing the world name later starts a new world.
                
              
                
                
                
                
                
              
                
              
                
            
                
          
                4. 
          
              4. 
            
                4
                
            
                
              
                
                
                Install BepInEx
                
                
              
                
              
                Downloads the current denikson-BepInExPack_Valheim and merges it into the server folder (BepInEx/, launcher scripts, doorstop config). Doesn't touch common.cfg.
                
              
                
                
                Output
                
                
                
              
                
            
                
          
                5. 
          
              5. 
            
                5
                
            
                
              
                
                
                Wire common.cfg to BepInEx
                
                
                
                  
                  
                
                
              
                
              
                Adds the four DOORSTOP_*/LD_* export lines LinuxGSM needs to launch through BepInEx instead of running Valheim bare — nothing existing in common.cfg is touched, and the file is backed up first. Doesn't start or restart anything.
                
              
                
            
                
          
                6. 
          
              6. 
            
                6
                
            
                
              
                
                
                Install ValheimEnforcer
                
                
              
                
              
                Installs MidnightMods-ValheimEnforcer as a normal BepInEx plugin. Its Mods.yaml appears on the first start and every mod feature becomes usable.
                
              
                
                
                Output
                
                
                
              
                
            
                
          
                7. 
          
              7. 
            
                7
                
            
                
              
                
                
                Install helper scripts
                
                
              
                
              
                Installs the scripts the other tabs call — backup, update check, update apply, and the two Mods helpers — plus their folders and the Python YAML library. A script that already exists and differs is kept as .bak first.
                
              
                
                
                Output
                
                
                
              
                
            
                
          
                8. 
          
              8. 
            
                8
                
            
                
              
                
                
                Start the server and check it
                
                
              
                
              
                Do this last, once steps 1–7 are done: the server starts once with everything in place, so no restart is needed. The first start creates the world and can take a few minutes — the checklist above fills in as it comes up (server running, game port open, world created, BepInEx and ValheimEnforcer loaded, Mods.yaml present). If you already started the server earlier, press Stop, wait until the Dashboard shows inactive, then Start.
